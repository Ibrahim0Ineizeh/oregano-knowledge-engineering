# OREGANO data

This package uses the **OREGANO V2.1 assessment distribution**. Source TSV files and the large generated ontology are not bundled.

Upstream resources:

- [OREGANO paper](https://doi.org/10.1038/s41597-023-02757-0)
- [OREGANO source repository](https://gitub.u-bordeaux.fr/erias/oregano)

Retrieve the same V2.1 input distribution used in the original work where available. The project does not claim that a current upstream download is byte-identical to the assessment archive. Check its version, columns, identifiers, and terms before using it for a reproduction.

Place `ACTIVITY.tsv`, `COMPOUND.tsv`, `DISEASES.tsv`, `EFFECT.tsv`, `GENES.tsv`, `INDICATION.tsv`, `PATHWAYS.tsv`, `PHENOTYPES.tsv`, `SIDE_EFFECT.tsv`, `TARGET.tsv`, and `OREGANO_V2.1.tsv` here. The first stage of the combined notebook generates `oregano.owl` in this folder.

The dataset belongs to its original authors and sources. Follow the upstream terms; this archival package does not grant new rights over it.
